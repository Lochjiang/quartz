### 1. 基础与编辑器设置 

- **Template folder location (模板文件夹位置):** * **解释：** 这是最基础的设置，告诉插件去哪里读取你的模板文件。
    
    - **当前状态：** 你已经设置为 `模板` 文件夹。以后所有写好的模板都必须放在这个文件夹里才能被识别。
        
- **Syntax highlighting on desktop/mobile (桌面端/移动端语法高亮):** * **解释：** 开启后，在编辑模式下，Templater 的代码（比如 `<% tp.file.title %>`）会高亮显示，方便你区分“模板代码”和“普通文字”。
    
    - **建议：** 桌面端建议**开启**（你已经开启）；移动端建议**关闭**（如图），因为可能会导致手机端的实时预览出现 Bug。
        
- **Automatic jump to cursor (自动跳转到光标位置):** * **解释：** 在模板中输入特定代码 `<% tp.file.cursor(1) %>`，开启此项后，插入该模板时，你的鼠标光标会自动跳到这个代码所在的位置，方便你直接开始打字。
    
    - **建议：** 非常实用的功能，建议**开启**。
        
- **Trigger Templater on new file creation (新建文件时自动触发):** * **解释：** 这是 Templater 的**核心神级功能**。开启后，只要你新建了一篇笔记，插件就会根据你的规则（比如在特定文件夹内新建）自动应用某个模板，并把里面的代码（如创建时间）转化为纯文本。
    
    - **建议：** 强烈建议**开启**！配合下方的文件夹规则配置，可以实现“新建日记自动填入今天日期”、“新建阅读笔记自动生成作者栏”等效果。
        


### 2. 快捷键与启动项 

- **Template hotkeys (模板快捷键):** * **解释：** 允许你为最常用的特定模板绑定一个键盘快捷键。
    
    - **当前状态：** 图中你已经添加了 `模板/模板.md` 这个文件。去 Obsidian 的“快捷键 (Hotkeys)”设置里搜索这个模板名字，就可以给它绑定比如 `Ctrl + T` 的快捷键，一键插入，无需每次都在命令面板里找。
        
- **Startup templates (启动模板):** * **解释：** 每次打开 Obsidian 时会在后台静默运行一次的模板。它不会输出任何文字，主要给高级用户用来注册一些事件钩子（Hooks）或初始化脚本。
    
    - **建议：** 如果不写高级代码，这项留空即可。
        


### 3. 高级脚本与系统命令

这一页主要是为懂编程（JavaScript）的**进阶用户**准备的，如果你只用基础的日期和标题变量，这部分可以完全不管。

- **Script files folder location (用户脚本文件夹):** * **解释：** 如果你自己写了 `.js` 格式的 JavaScript 脚本，把它们放在这里，Templater 就可以调用你写的自定义函数。
    
- **User script intellisense (脚本代码提示):** * **解释：** 写代码时的智能提示方式。保持默认即可。
    
- **Enable user system command functions (启用系统命令功能):** * **解释：** 极其强大的功能。允许你的笔记通过 Templater 操控你的电脑系统（比如执行 CMD、终端命令、运行 Python 脚本、调用本地软件）。
    
    - **建议：** 存在一定安全风险（如果误运行来路不明的模板可能会执行恶意代码）。除非你清楚自己在做什么，否则建议**保持关闭**（你当前是关闭状态）。
