### 键值对打包

```python
keys = ['name', 'age', 'city']
values = ['Alice', 25, 'New York']

# 一行代码搞定
result = dict(zip(keys, values))

print(result) 
# 输出: {'name': 'Alice', 'age': 25, 'city': 'New York'}
```
