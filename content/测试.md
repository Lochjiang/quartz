# 广义相对论与爱因斯坦场方程的数学推导

本页面旨在展示广义相对论（General Relativity）的核心数学结构，特别是从黎曼几何的曲率张量推导出爱因斯坦场方程（Einstein Field Equations, EFE）的过程。

## 1. 黎曼几何与曲率张量

在四维时空流形 $\mathcal{M}$ 上，引入度规张量 $g_{\mu\nu}$。为了定义导数，我们采用列维-奇维塔（Levi-Civita）联络，其克里斯托费尔符号（Christoffel symbols）定义为：

$$\Gamma^\lambda_{\mu\nu} = \frac{1}{2} g^{\lambda\sigma} \left( \partial_\nu g_{\sigma\mu} + \partial_\mu g_{\sigma\nu} - \partial_\sigma g_{\mu\nu} \right)$$

通过共变导数 $\nabla_\mu$ 的非对易性，我们可以定义黎曼曲率张量（Riemann Curvature Tensor）：

$${R^\rho}_{\sigma\mu\nu} = \partial_\mu \Gamma^\rho_{\nu\sigma} - \partial_\nu \Gamma^\rho_{\mu\sigma} + \Gamma^\rho_{\mu\lambda}\Gamma^\lambda_{\nu\sigma} - \Gamma^\rho_{\nu\lambda}\Gamma^\lambda_{\mu\sigma}$$

### 张量缩并与里奇张量

对黎曼曲率张量进行指标缩并（Contraction），得到里奇张量（Ricci Tensor）：

$$R_{\sigma\nu} = {R^\mu}_{\sigma\mu\nu} = \partial_\mu \Gamma^\mu_{\nu\sigma} - \partial_\nu \Gamma^\mu_{\mu\sigma} + \Gamma^\mu_{\mu\lambda}\Gamma^\lambda_{\nu\sigma} - \Gamma^\mu_{\nu\lambda}\Gamma^\lambda_{\mu\sigma}$$

再次利用度规张量缩并，得到里奇标量（Ricci Scalar）：

$$R = g^{\sigma\nu} R_{\sigma\nu} = g^{\mu\nu} \left( \partial_\lambda \Gamma^\lambda_{\nu\mu} - \partial_\nu \Gamma^\lambda_{\lambda\mu} + \Gamma^\lambda_{\lambda\rho}\Gamma^\rho_{\nu\mu} - \Gamma^\lambda_{\nu\rho}\Gamma^\rho_{\lambda\mu} \right)$$

## 2. 爱因斯坦张量与比安基恒等式

黎曼曲率张量满足二次比安基恒等式（Second Bianchi Identity）：

$$\nabla_\lambda {R^\rho}_{\sigma\mu\nu} + \nabla_\mu {R^\rho}_{\sigma\nu\lambda} + \nabla_\nu {R^\rho}_{\sigma\lambda\mu} = 0$$

通过对指标进行两次缩并：

1. 乘以 $g^{\sigma\nu}$ 缩并 $\sigma$ 与 $\nu$
    
2. 乘以 $g^{\mu\lambda}$ 并利用度规标量不变性 $\nabla_\alpha g_{\mu\nu} = 0$
    

我们可以得到守恒流恒等式：

$$\nabla_\mu \left( R^{\mu\nu} - \frac{1}{2}g^{\mu\nu}R \right) = 0$$

由此，我们定义**爱因斯坦张量（Einstein Tensor）** $G^{\mu\nu}$ 为：

$$G_{\mu\nu} = R_{\mu\nu} - \frac{1}{2}g_{\mu\nu}R$$

该张量自动满足共变散度为零的性质，即 $\nabla^\mu G_{\mu\nu} = 0$。

## 3. 爱因斯坦-希尔伯特作用量原理

爱因斯坦场方程可以通过对爱因斯坦-希尔伯特作用量（Einstein-Hilbert Action）进行变分推导得出。总作用量 $S$ 由重力部分 $S_G$ 和物质部分 $S_M$ 组成：

$$S = S_G + S_M = \int_{\mathcal{M}} \left[ \frac{1}{2\kappa} R + \mathcal{L}_m \right] \sqrt{-g} \, d^4x$$

其中 $g = \det(g_{\mu\nu})$ 是度规张量的行列式，$\mathcal{L}_m$ 是物质的拉格朗日量密度，$\kappa$ 为待定常数。

### 作用量的变分推导

根据最小作用量原理，对度规的逆变形式 $\delta g^{\mu\nu}$ 进行变分，要求 $\delta S = 0$：

$$\delta S_G = \frac{1}{2\kappa} \int_{\mathcal{M}} \left[ \delta(R) \sqrt{-g} + R \delta(\sqrt{-g}) \right] d^4x$$

利用雅可比公式（Jacobi's formula）对行列式求导：

$$\delta\sqrt{-g} = -\frac{1}{2\sqrt{-g}}\delta g = -\frac{1}{2}\sqrt{-g} \, g_{\mu\nu}\delta g^{\mu\nu}$$

同时，里奇标量的变分为：

$$\delta R = \delta(g_{\mu\nu}R^{\mu\nu}) = R_{\mu\nu}\delta g^{\mu\nu} + g^{\mu\nu}\delta R_{\mu\nu}$$

利用帕拉蒂尼恒等式（Palatini Identity），可以证明 $g^{\mu\nu}\delta R_{\mu\nu}$ 项形成一个全微分（散度项），在流形边界为零的假设下，其积分项消失：

$$\int_{\mathcal{M}} g^{\mu\nu}\delta R_{\mu\nu} \sqrt{-g} \, d^4x = \int_{\mathcal{M}} \nabla_\lambda \left( g^{\mu\nu} \delta \Gamma^\lambda_{\mu\nu} - g^{\mu\lambda}\delta\Gamma^\nu_{\mu\nu} \right) \sqrt{-g} \, d^4x = 0$$

因此，重力部分的变分简化为：

$$\delta S_G = \frac{1}{2\kappa} \int_{\mathcal{M}} \left( R_{\mu\nu} - \frac{1}{2}g_{\mu\nu}R \right) \delta g^{\mu\nu} \sqrt{-g} \, d^4x$$

对于物质部分，我们定义能量-动量张量（Energy-Momentum Tensor） $T_{\mu\nu}$ 为：

$$T_{\mu\nu} := -2 \frac{1}{\sqrt{-g}} \frac{\delta(\sqrt{-g}\mathcal{L}_m)}{\delta g^{\mu\nu}} = -2\frac{\delta \mathcal{L}_m}{\delta g^{\mu\nu}} + g_{\mu\nu}\mathcal{L}_m$$

代入总变分方程 $\delta S_G + \delta S_M = 0$，得到：

$$\frac{1}{2\kappa} \left( R_{\mu\nu} - \frac{1}{2}g_{\mu\nu}R \right) - \frac{1}{2}T_{\mu\nu} = 0$$

## 4. 最终方程与牛顿极限

通过牛顿弱场极限（Weak-field limit）的一阶近似，令度规满足 $g_{\mu\nu} = \eta_{\mu\nu} + h_{\mu\nu}$ 且 $|h_{\mu\nu}| \ll 1$，场方程应退化为牛顿引力的泊松方程（Poisson's equation）：

$$\nabla^2 \Phi = 4\pi G_N \rho$$

由此确定耦合常数 $\kappa = \frac{8\pi G_N}{c^4}$（此处 $G_N$ 为牛顿万有引力常数，$c$ 为光速）。若引入宇宙学常数 $\Lambda$，则得到最终形式的**爱因斯坦场方程**：

$$R_{\mu\nu} - \frac{1}{2}g_{\mu\nu}R + \Lambda g_{\mu\nu} = \frac{8\pi G_N}{c^4} T_{\mu\nu}$$
